AuroraUI 开发者 Wiki

面向服务端的 Minecraft 界面框架。用 YAML 描述「画布」，由服务端向单个玩家私有地渲染文字、图片、物品、方块、 矩形、边框与折线，并通过屏幕对齐的「命中区」接管点击、悬浮提示与导航。

本 Wiki 面向开发者：讲清 YAML 菜单格式、动作/条件语言、坐标几何、占位符、 资源包管线、配置项、命令权限，以及给第三方插件使用的公开 API。 Java 21Paper / MC 1.21.x

1. 它是什么

AuroraUI 不是传统的「箱子菜单」插件，而是一个服务端驱动的 UI 框架：

画布 canvas

固定在玩家视野前方的逻辑平面，坐标以逻辑像素为单位，原点在画布中心，X 向右、Y 向上。

前端 frontend

画布上的视觉节点树（可嵌套分组），只对目标玩家可见，纯展示。

后端 backend

屏幕对齐、不继承任何前端变换的矩形命中区，负责点击动作、悬浮提示、条件与拒绝动作。

动作 / 条件 DSL

一套文本 DSL，用于点击行为、打开/关闭菜单、状态读写、经济/物品操作等。

资源包管线

把 plugins/AuroraUI/images 下的 PNG 自动打包成资源包与位图字体。

公开 API

第三方插件通过 Bukkit ServicesManager 获取 AuroraUIApi，注册路由与应用会话。
服务端权威：菜单始终由服务端渲染与判定。可选的 Fabric 编辑器只用于管理端可视化编辑，玩家无需安装任何客户端模组。

2. 运行时数据目录

插件首次启用会在 plugins/AuroraUI/ 下创建/释放：

plugins/AuroraUI/

│  ├─ example.yml
│  ├─ details.yml
│  ├─ m4-resources.yml
│  └─ m5-animation.yml

3. 命令与权限

主命令：/auroraui（别名 /aurora）。

普通用户（auroraui.use，默认所有玩家）

命令说明
/aurora open <菜单ID> [参数...]打开菜单
/aurora close关闭当前菜单
/aurora mode <touch|mouse>切换输入模式（别名 crosshair/cursor）
/aurora animate <轨道ID>播放动画
/aurora stop-animation <轨道ID>停止动画
/aurora pointer查看指针诊断

管理员（auroraui.admin，默认 OP）

命令说明
/aurora edit <菜单ID>打开可视化编辑器
/aurora preview <菜单ID> [frontend|backend]只读预览
/aurora reload [all]重载菜单/动画/配置（all 同时重建资源包）
/aurora validate仅校验菜单，不应用
/aurora resources重建资源包
/aurora list / templates / animations列出菜单/模板/动画
/aurora performance [reset]性能统计
/aurora status插件总览状态

自定义打开命令：菜单的 open-commands 会注册成独立命令（不带 /），注册时若与已有命令冲突会报错。

快捷开关：默认 Shift+F 切换唯一的主菜单（config.yml → shortcuts.shift-f）。

4. YAML 菜单格式（完整）

解析器是严格模式：未知字段一律报错，因此拼写错误会在加载期直接暴露。错误信息形如 example.yml.backend.card-area.label: 不支持的字段。

4.1 根字段

schema-version: 1          # 必填，必须为 1
id: example                # 必填，正则 [a-z0-9][a-z0-9_-]*
permission: auroraui.use   # 可选，额外权限节点
open-commands: [arc]       # 可选，注册为独立命令（小写、不含 /、不重复、≤64 字符）
main-menu: true            # 可选，整个菜单集合中有且仅有一个为 true
canvas: { ... }
frontend: { ... }
backend: { ... }
events: { ... }
约束：整组菜单中必须有且仅有一个 main-menu: true，否则加载失败。

4.2 canvas

canvas:
  width: 320            # 逻辑宽度（px），默认 320
  height: 180           # 逻辑高度（px），默认 180
  pixels-per-block: 100 # 每方块像素数，默认 100
  distance: 3           # 设计距离（方块），默认 3

四项均为正数。

4.3 frontend 视觉节点

每个键为节点 ID，必须在「前端 + 后端 + 所有嵌套分组」范围内全局唯一（不能含 /、\ 或控制字符）。

通用字段（所有类型）

type: text          # 必填，节点类型
offset: {x: 0, y: 0, z: 0}   # 相对父级平移，逻辑像素
rotation: {x: 0, y: 0, z: 0} # 旋转（度）
scale: {x: 1, y: 1}          # 缩放，两轴均不能为 0
visible: true                # 是否可见（隐藏请用此项，而不是把 scale 设为 0）

各类型专有字段

type专有字段说明
groupchildren子节点映射，可嵌套
rectanglewidth, height, color, opacity实心矩形
linewidth, thickness, color, opacity折线/线条（用 thickness 而非 height）
framewidth, height, thickness, color, opacity边框；要求 thickness*2 < min(width,height)
textcontent, size, font, opacity, line-width, alignment, update文本
imagesource/path/image/material（四选一）, width, height, opacity, update资源包图片
itemmaterial, context原版物品展示
blockblock-data原版方块展示

字段细节

  • color：必须带引号的 '#RRGGBB'（不区分大小写）；透明度单独用 opacity。
  • opacity：0..255，默认 255。
  • text.size：正数，默认 10.0。
  • text.font：namespace:path，默认 minecraft:default。
  • text.alignment：left / center / right，默认 center。
  • text.line-width：正整数，默认 200。
  • image.source：虚拟根 / 下的小写 PNG 路径，如 /ui/logo.png；% 变量路径允许大写（用于动态贴图）。
  • item.context：GUI（默认）/ HEAD / FIXED / GROUND / NONE / FIRSTPERSON_LEFTHAND / FIRSTPERSON_RIGHTHAND / THIRDPERSON_LEFTHAND / THIRDPERSON_RIGHTHAND。
  • update：每节点的周期刷新（tick）。-1 表示不周期刷新；>0 为间隔；0 或更小非法。目前用于 text/image（内容刷新）与后端 tooltip。

示例

frontend:
  viewport-content:
    type: group
    scale: {x: 0.427, y: 0.427}
    children:
      background:
        type: rectangle
        width: 320
        height: 180
        color: '#182031'
        opacity: 235
      title:
        type: text
        content: '&fAuroraUI - %player_name%'
        offset: {y: 58, z: 1}
        size: 12
        update: 20
      sword:
        type: item
        material: minecraft:diamond_sword
        context: GUI
        offset: {x: 72, y: 0, z: 2}
        scale: {x: 40, y: 40}
      block:
        type: block
        block-data: 'minecraft:grass_block[snowy=false]'
        offset: {x: 120, y: 48, z: 2}
        rotation: {x: -20, y: 35}
        scale: {x: 30, y: 30}

4.4 backend 命中区

后端区域是独立的、屏幕对齐的矩形，不继承任何前端变换。坐标 x/y 以画布中心为原点、+x 向右、+y 向上；width/height 是完整边长（命中判定为 x ± width/2、y ± height/2）。

backend:
  card-area:
    x: -27.755        # 中心 X，默认 0
    y: -2.135         # 中心 Y，默认 0
    width: 46.97      # 必填，正数
    height: 23.485    # 必填，正数
    priority: 0       # 命中优先级，越大越先命中，默认 0
    tooltip:          # 字符串或字符串列表；支持占位符
      - '&f独立对齐的矩形命中区'
      - '&7玩家: %player_name%'
    update: 20        # tooltip 周期刷新（tick），同 update 规则
    condition: 'perm auroraui.use'   # 命中前置条件
    actions: { ... }  # 点击动作（见第 5 节）
    deny: [ ... ]     # condition 不满足时执行的动作

命中顺序：先按 priority 降序，再按文档顺序取第一个命中的区域。

常见坑：把 label/color/textSize 等视觉字段写进 backend 会直接解析失败——视觉只属于 frontend。

4.5 events

events:
  open: 'sound: BLOCK_CHEST_OPEN-1-1'
  close: 'sound: BLOCK_CHEST_CLOSE-1-1'

open / close 均可为：动作字符串、动作列表、单项动作映射或条件动作组。

5. 动作语言（Action DSL）

动作既可写成字符串，也可写成「单项动作映射」：

actions:
  all: 'sound: UI_BUTTON_CLICK-1-1'
  right:
    - condition: 'perm auroraui.use'
      actions:
        - 'tell: &aHello'
      deny:
        - 'tell: &c无权限'

5.1 点击触发键

all（别名 any）、left、right、shift（左右 Shift 点击都算）、shift-left、shift-right。

运行时中，非潜行时主键为右键，潜行时使用 Shift+右键；左键通过捕获实体由攻击事件触发。

5.2 条件动作组

一个组的可用键（含别名）：priority（priority/pri/pris）、condition（condition/require/req…）、actions（actions/list/click/execute/cmd…）、deny（deny/deny-list…）。每组至少要有一个 actions 或 deny。

5.3 内置动作（规范名）

tellraw富文本（JSON 或 <文本@hover=..@command=..> 标签）文本

5.4 序列与内联选项

  • 序列分隔：_||_ 或 &&&。序列内选项最多的那条的选项会共享给全部。
  • 内联选项（写在动作末尾）：
    选项语法含义
    延迟<delay=20> / <wait:20>tick
    概率<chance=0.5> / <rate:0.5>0..1
    条件{condition=...} / {requirement: ...}条件表达式
    目标玩家<players>（全体在线）/ <players=条件>条件筛选
     
actions:
  right:
    - 'sound: UI_BUTTON_CLICK-1-1 _||_ delay: 10 _||_ open: details'
    - 'command: give %player_name% diamond 1 <chance=0.3>'

5.5 输入捕获（Catcher）

跨版本目前支持 CHAT 类型：玩家点击后开始捕获聊天输入。结构为单项映射：

actions:
  right:
    - input-catcher:
        stage-id:
          type: CHAT
          start: [...]     # 开始阶段（别名 before）
          cancel: [...]    # 取消阶段
          end: [...]       # 结束阶段（别名 after）

SIGN / ANVIL / BOOK 需要额外的版本输入适配器，当前不受支持。

6. 条件语言（Condition DSL）

条件为字符串，可组合：

  • true / false
  • perm <节点> / permission <节点>（* 前缀会被忽略）
  • not <条件> / !<条件>
  • A && B、A || B、( ... )
  • all[a; b] / any[a, b]（分隔符 ; 或 ,，支持嵌套括号）
  • 比较：check 前缀可选；左侧/右侧支持占位符展开
    • is（等于）、is not（不等）、contains（包含）
    • >=、<=、>、<、==、!=
    • 两侧都能解析为数字时按数字比较，否则忽略大小写按字符串比较
  • 真值判定：包含 % 的表达式，或以 * / 反引号 / " / ' 开头者，按真值处理（true/yes/on/非 0 数字为真）
condition: 'perm auroraui.use && check %player_world% is world'
condition: 'any[perm vip; perm staff]'

7. 坐标与几何

  • 逻辑画布：单位 px，原点在中心，+x 右、+y 上、+z 朝向观察者。
  • 像素/方块：canvas.pixels-per-block 决定逻辑像素与世界方块的换算；MenuPlane.project 把玩家视线射线投影到画布得到逻辑坐标，toWorld 反之。
  • 前端变换顺序（Transforms.local，自内而外）：translate(offset) → rotateZ → rotateX → rotateY → scale(sx, sy, 1)。
  • 后端命中：与前端视觉/深度/变换完全无关；命中判定为矩形半宽/半高包含，按 priority 降序、文档顺序取首个命中。
  • 画布锚定：首次打开时固定世界锚点与坐标轴（遵循 offset.yml），后续切换路由复用同一平面，不随视角漂移；传送/跨维度/重生会重新锚定。
由于前端分组可带 scale，样板示例中 viewport-content 组用了 scale: 0.427，因此后端命中区坐标 ≈ 前端坐标 × 0.427。

8. 占位符

在动作、content、tooltip、condition 等文本位置均可使用：

语法含义
{meta:key} / {m:key}临时状态（会话级）
{data:key} / {d:key}玩家持久状态
{globaldata:key} / {gdata:key} / {g:key}全局状态
{0}、{1} …菜单参数（open/命令传入）
%auroraui_meta_KEY%同上（命名式）
%auroraui_data_KEY%持久状态
%auroraui_globaldata_KEY%全局状态
%auroraui_args_N%第 N 个参数
%player_name%玩家名
%player_uuid%UUID
%player_world%世界名
%player_x% / %player_y% / %player_z%坐标（保留 2 位小数）
%...%若安装 PlaceholderAPI，则交给其解析

规则：未能解析的占位符会替换为字符串 null（便于调试与条件判定）。

9. 资源包管线

来源目录：plugins/AuroraUI/images（路径必须全小写）。构建产物：generated/auroraui-resourcepack.zip，同时解包到 generated/resourcepack/。

  • 贴图落位：assets/auroraui/textures/images/<相对路径>
  • 位图字体：assets/auroraui/font/images.json，字体键 auroraui:images，height=8、ascent=4
  • 私用区码位：每个图片分配一个 0xE000–0xF8FF 的唯一码位，记录在 generated/images.index，保证跨次构建稳定
  • pack.mcmeta：pack_format: 34，supported_formats 34–84
  • 限制：图片数 ≤ 4096；单图尺寸 ≤ 4096×4096；单文件 ≤ 16 MiB；总量 ≤ 128 MiB
  • 热构建保护：已发布图片不能在热构建中删除，需先移除引用再完整重启

九宫格 tooltip 皮肤

tooltip.yml 的 skin 使用 background + 可选 frame 合成九宫格，字体键 auroraui:tooltip_slices（ascent=2）：

  • background 与 frame 的 PNG 尺寸必须相同
  • border > 0 且 border*2 < PNG 宽/高
  • 生成的切片写入 /_generated/nine_slice/*.png

CraftEngine

CraftEngine 作为自定义内容集成：资源包 zip 会通过 CraftEngine 的缓存事件合并；打包版 CraftEngine 缺失时可自动释放（见第 11 节配置）。

10.2 路由（轻量入口）

ui.registerRoute(this, "myplugin:shop", (player, arguments) -> ui.open(player, "shop-home", arguments));

命名空间路由（namespace:path）可以在菜单里用 open: myplugin:shop 打开。

10.3 应用会话（重逻辑）

应用为每个打开它的玩家创建一个会话：

AuroraUIApplicationHandle handle = ui.registerApplication(
    this, "myplugin:shop",
    AuroraUIApplicationOptions.builder()
        .permission("myplugin.shop")
        .captureMouseScroll(true)
        .build(),
    context -> new ShopSession(context)
);

AuroraUIApplicationSession 可按需重写回调：onSurfaceChanged、onPointerModeChanged、onPointerMove、onActivate、onScroll、onTick、onClose。

AuroraUIApplicationContext 提供：player/applicationId/arguments/owner、surface()、pointer()、pointerMode()、isActive()、setCursorInteractive()、spawnPrivate()、track()、execute()、runLater()、runTimer()、openMenu()、openApplication()、back()、close()。

AuroraUIApplicationOptions.Builder：permission、captureMouseScroll、inheritCanvas、canvas、tickInterval。

从 YAML 打开应用：

actions:
  right:
    - 'open-app: myplugin:shop featured'

11. 配置项

11.1 config.yml

language:
  default: zh_CN           # 控制台/日志语言
  follow-player-locale: true
shortcuts:
  shift-f: true            # Shift+F 切换主菜单（false 则不干预副手交换）

  auto-install: true
  file-name: CraftEngine.jar

  policy: player-choice    # player-choice | force-touch | force-mouse
  default: touch
  cursor:
    sensitivity-x: 2.0
    sensitivity-y: 2.0
    clamp-margin: 3.0
    size: 5.0
    z: 5.0

11.2 offset.yml（屏幕全局摆放）

touch / mouse 各含 distance（眼到屏幕距离，方块）与 offset{x,y,z}（屏幕本地平移，方块；x 右、y 上、z 朝向观察者）。编辑器中默认走 mouse 模式。

11.3 tooltip.yml

touch / mouse 各含 offset、anchor（四角）、wrap、size、line-width、background，以及 skin（九宫格）：background、frame、border、padding、min-size、size-adjust、offset、scale、text-offset、seam-overlap、glyph-offset、column-offset、row-offset。

11.4 animations.yml

schema-version: 1
transitions:
  my-slide:
    enter:  {duration: 8, easing: ease-out, offset: {x: -36, y: 0, z: 0}, scale: {x: 0.9, y: 0.9}}
    exit:   {duration: 6, easing: ease-in,  offset: {x: 0, y: -28, z: 0}, scale: {x: 0.92, y: 0.92}}
    switch: {duration: 7, easing: ease-out, offset: {x: 36, y: 0, z: 0}, scale: {x: 0.94, y: 0.94}}
tracks:
  model-spin:
    target: spinner            # 前端节点 ID
    property: rotation         # rotation | content | opacity | offset | scale
    duration: 60
    easing: linear
    loop: repeat               # repeat | ping-pong
    trigger: open              # open | api
    keyframes:
      - {at: 0, value: {x: -15, y: 0, z: 0}}
      - {at: 1, value: {x: -15, y: 360, z: 0}}
menus:
  m5-animation:
    transition: my-slide
    tracks: [model-spin]
  • transitions：菜单 enter/exit/switch 过渡。
  • tracks：可复用的节点轨道；trigger: open 随菜单打开播放，trigger: api 需通过 play-animation/API 触发。
  • menus：把某菜单绑定到某 transition，并列出随菜单激活的 tracks。

12. 编辑器协议

protocol 模块提供无第三方依赖的通信契约（EditorProtocol.VERSION），由服务端与 Fabric 编辑器共享。/aurora status 会显示当前协议版本。编辑器通过 mouse 模式打开，属管理端工具，玩家端不需要安装。

编辑器的安装、打开方式、界面布局、快捷键与常见问题，见 AuroraUIEditor 使用 Wiki。

13. 加载期校验与常见错误

  • 严格字段：任何未知字段（如把 label 写进 backend）都会导致 不支持的字段 并拒绝加载该菜单。
  • ID 唯一：节点 ID 在前端+后端+嵌套组内必须唯一。
  • 唯一主菜单：main-menu: true 有且仅有一个。
  • open 目标必须存在：open: 指向的菜单 ID 必须已定义，或为 namespace:path 扩展路由；动态目标（含 %/{）豁免。
  • refresh 目标必须存在：refresh 的参数必须是本菜单内某动态文字节点或后端区域 ID。
  • open-commands 冲突：自定义命令不得与已注册命令重名。
  • 图片路径：仅小写、.png、虚拟根 / 下；不存在于资源包会渲染失败。

调试流程：先 /aurora validate 校验，再 /aurora reload all 应用并重建资源包。
