欢迎来到 AuroraStudio

我们是一个专注于 Minecraft 服务端与客户端工具开发的独立团队。
目前主要项目是 AuroraUI —— 一套面向 Paper 服务器的服务端驱动界面框架，以及配套的可视化编辑器。

◆  Paper / Java 服务端插件  ·  ◆  Fabric 客户端模组  ·  ◆  可视化编辑器

核心项目

AuroraUI

Paper 服务端驱动的 Minecraft 界面框架。用 HTML 菜单描述 UI，通过画布渲染文字、图片、物品、方块与命中区，支持丰富的动作与条件语言。

Java 21 · Paper · MC 1.21.x

AuroraUIEditor

AuroraUI 的可视化编辑工具（Fabric 客户端模组）。在单人游戏或 Fabric 服务器上直接编辑菜单，所见即所得。

Fabric · MC 1.21.11 · 客户端

关于团队

AuroraStudio 是一个小型开发团队，致力于让 Minecraft 服务器拥有更灵活、更美观的自定义界面体验。 我们的理念是降低 UI 开发门槛——设计师用 HTML 写菜单，管理员用编辑器拖拽调整，开发者通过 Java API 深度集成。

如需联系或了解更多，请访问我们的开源仓库或社区页面。
