AuroraUI

服务端驱动的 Minecraft 界面框架。用 HTML 描述画布，通过命中区接管点击、悬浮提示与导航，支持 Paper / Java 插件生态。

Java 21 Paper MC 1.21.x
✦

AuroraUIEditor

可视化编辑工具（Fabric 客户端模组）。在单人游戏或 Fabric 服务器上直接编辑菜单，所见即所得，0.2.0 起支持 UI 创建与读取。

Fabric MC 1.21.11 客户端

为什么选择 AuroraUI

服务端权威

菜单始终由服务端渲染与判定，玩家无需安装任何客户端模组即可正常使用。

HTML 驱动

用熟悉的前端语言描述 UI 结构，设计师与开发者分工明确，降低协作门槛。

可视化编辑

配套 AuroraUIEditor，在集成服务器或 Paper 服上直接拖拽调整，所见即所得。

丰富的动作语言

支持点击事件、条件判断、状态读写、经济/物品操作等，兼容 TrMenu 风格别名。

完整公开 API

提供全新的 DSL 入口 AuroraUI，声明锚点、打开菜单、路由分发一目了然。

资源包管线

自动将图片目录打包为资源包，支持位图字体、九宫格 tooltip 皮肤与 CraftEngine 集成。

关于 极光创想

极光创想（AuroraStudio）是一个小型独立开发团队，致力于让 Minecraft 服务器拥有更灵活、更美观的自定义界面体验。 我们的理念是降低 UI 开发门槛——设计师用 HTML 写菜单，管理员用编辑器拖拽调整，开发者通过 Java API 深度集成。 所有项目基于开源协议，欢迎社区参与共建。
